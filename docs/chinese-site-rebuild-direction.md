# TEAO 中文独立站复刻与本土化重构方向

调研日期：2026-06-06  
目标域名：www.chinateao.com  
参考基底：英文国际站 teao-damper.com / 当前 `teao-website` 项目

## 1. 总体判断

中文站不要做成英文站的逐字翻译版，而应该做成“英文站能力体系的中文本土化版本”。

英文站适合海外 B2B 客户，重视专业叙述、SEO/GEO 语义覆盖、品牌感和技术可信度。国内客户浏览习惯更直接：先看产品、工厂、认证、客户、产能、案例、联系方式，快速判断“是不是厂家、有没有实力、能不能定制、怎么报价”。所以中文站应复用英文站的产品数据、图片视频、制造能力、客户背书和询盘逻辑，但页面表达要更短、更直观、更强转化。

核心原则：

- 复刻底层能力，不复刻长文案节奏。
- 首页第一屏就回答：做什么、强在哪、服务谁、怎么联系。
- 产品页用参数、图片、视频、图纸、应用场景说话，正文不要过长。
- 制造实力和质量控制要前置，国内客户非常看重“真工厂、真设备、真检测”。
- 移动端优先考虑电话、微信、图纸询盘、快速导航。
- 切换中文站前必须做旧 URL 清单和 301 迁移，不要直接整站覆盖。

建议中文站主定位：

> 特澳 TEAO：汽车内饰阻尼器、齿轮阻尼器、轴向阻尼器与锁扣定制厂家

辅助定位：

- 20+ 年阻尼器研发制造经验

- 汽车主机厂 / Tier-1 采购
- 结构工程师、项目工程师
- 家电、卫浴、办公设备厂商
- 正在找阻尼器、锁扣、缓冲结构解决方案的老板或采购
- 从百度、360、搜狗、B2B 平台或微信转来的询盘客户

他们最关心：

- 你是不是源头厂家？
- 有哪些产品型号？
- 有没有汽车客户和认证？
- 能不能按图纸或样品定制？
- 参数、尺寸、扭矩范围是否合适？
- 怎么快速报价？

## 5. 首页结构建议

首页应更像国内制造业官网，而不是海外品牌官网。建议控制首页可见文案，把重点放在产品、图片、实力数字和询盘入口。

### 5.1 第一屏

目标：3 秒内让客户知道 TEAO 是什么公司。

建议内容：

- 主标题：汽车内饰阻尼器与锁扣定制厂家
- 副标题：20+ 年阻尼器研发制造经验，支持齿轮阻尼器、轴向阻尼器、手套箱阻尼器、锁扣及定制缓冲机构。
- 核心标签：IATF 16949、ISO 14001、8000 万件年产能、100% 扭矩检测、支持图纸/样品定制。
- CTA：发送图纸获取选型建议、电话咨询、添加微信。
- 视觉：工厂实拍 + 产品实物组合，不要只用抽象背景。

### 5.2 产品中心

用大图卡片展示 5 到 6 类产品，每张卡片要有：

- 中文主名称
- 常用别名
- 典型应用
- 可定制项
- 立即查看 / 获取报价

示例：

- 齿轮阻尼器 / 旋转阻尼器：杯托、眼镜盒、储物盒、汽车内饰开合机构。
- 轴向阻尼器 / 圆筒阻尼器 / 桶形阻尼器：拉手、滑动结构、缓开缓闭机构。
- 手套箱阻尼器：汽车手套箱、收纳盒、内饰面板。
- 锁扣：Push-Push 锁扣、汽车内饰锁止释放机构。

### 5.3 应用领域

国内客户很容易从“应用场景”理解产品价值。建议把应用放在首页中上部，而不是很靠后。

优先展示：

- 汽车杯托
- 手套箱
- 扶手箱
- 眼镜盒
- 充电口盖
- 门把手 / 储物盒
- 马桶盖 / 家电盖板 / 办公设备盖板

每个应用卡片最好包含：

- 场景图或短视频
- 使用问题：开合过快、异响、撞击、手感差
- TEAO 解决方案：稳定扭矩、静音缓冲、定制安装
- 推荐产品型号

### 5.4 制造实力

国内站要把“我们是厂家”讲清楚。建议首页至少有一个强制造模块：

- 模具开发
- 注塑生产
- 自动化装配
- 扭矩检测
- 可靠性测试
- 批量交付

素材优先级：

1. 真实工厂视频
2. 产线和设备照片
3. 检测设备照片
4. 产能和质量数字
5. 简短文字说明

### 5.5 质量认证

质量模块不要只放证书图片，应该让客户知道质量怎么管：

- 来料检验
- 注塑过程控制
- 装配过程控制
- 100% 扭矩检测
- 寿命测试
- 出货检验
- 批次追溯

证书展示：

- IATF 16949
- ISO 14001
- 专利证书
- 可公开展示的客户/项目背书

### 5.6 客户与案例

如果客户 Logo 已获得公开展示授权，可以在首页放汽车客户墙。国内客户对客户背书非常敏感，这一块能显著增强信任。

建议表达方式：

- “服务汽车及家电供应链客户”
- “应用于汽车内饰、家电、卫浴、办公设备等多个行业”
- Logo 下方不要写夸张承诺，只写真实可验证信息。

### 5.7 项目流程

英文站的项目流程可以复刻，但中文表达要更直接：

1. 提交图纸/样品/应用需求
2. 工程师评估结构与扭矩
3. 打样测试与手感调整
4. 开模/量产/交付

每一步配一个小图标和一句话即可。

### 5.8 底部询盘

底部 CTA 要强：

- 上传图纸或发送样品，获取阻尼器选型方案
- 电话
- 邮箱
- 微信二维码
- 地址
- 表单：姓名、公司、电话、产品类型、年用量、应用场景、上传图纸

移动端底部建议固定三个入口：

- 电话咨询
- 加微信
- 发图纸

## 6. 页面模板建议

### 6.1 产品列表页

产品列表页要更像选型工具，而不是文章列表。

建议功能：

- 分类筛选
- 扭矩范围筛选
- 阻尼方向筛选：单向、双向
- 安装方式筛选：螺丝、卡扣、齿轮、插入式等
- 应用筛选：杯托、手套箱、眼镜盒、拉手、家电等
- 卡片视图 + 表格视图
- 支持型号搜索

产品卡片信息：

- 型号
- 产品图
- 扭矩范围
- 阻尼方向
- 安装方式
- 典型应用
- 查看详情
- 获取报价

### 6.2 产品详情页

产品详情页建议采用“左图右参数”的国内常见结构：

首屏：

- 产品图 / 视频 / 尺寸图
- 型号
- 中文名称和常用别名
- 核心参数
- 适用场景
- CTA：获取报价、发送图纸、电话咨询

下方 Tabs：

- 产品概述
- 规格参数
- 尺寸图
- 性能曲线
- 材料说明
- 应用视频
- 选型建议
- 相关产品
- FAQ

正文策略：

- 可见正文短，参数表和图纸优先。
- SEO 内容可以放在“选型说明 / FAQ / 技术说明”里，避免把首屏做成长文。
- 产品别名要自然出现，例如“齿轮阻尼器也常被称为旋转阻尼器”，“轴向阻尼器也常被称为圆筒阻尼器或桶形阻尼器”。

### 6.3 应用页

应用页要围绕“场景痛点 + 推荐产品”设计。

模板：

- 应用场景主图
- 典型问题
- 推荐阻尼方案
- 推荐型号
- 应用视频
- 成功案例或可公开客户
- 询盘入口

例如汽车内饰页：

- 杯托缓开缓闭
- 手套箱缓降
- 扶手箱静音开合
- 眼镜盒缓冲
- 充电口盖缓冲
- 门把手回弹控制

### 6.4 制造实力页

建议做成强视觉页面：

- 公司简介
- 工厂面积、年产能、成立时间、核心设备
- 模具能力
- 注塑能力
- 自动化装配
- 实验室与检测
- 质量追溯
- 工厂视频

这页是国内客户判断供应商可信度的关键页面。

### 6.5 质量认证页

建议不是单纯证书墙，而是“质量体系 + 检测流程 + 证书”：

- IATF 16949 / ISO 14001
- 扭矩检测
- 寿命测试
- 高低温测试
- 外观检测
- 批次追溯
- 100% 检测说明

### 6.6 技术支持页

保留英文站里的工具思路，但中文化：

- 扭矩单位换算
- 阻尼器选型指南
- 常见问题
- 产品资料下载
- 图纸上传
- 文章：如何选择齿轮阻尼器、如何选择轴向阻尼器、汽车杯托阻尼器选型等

## 7. 视觉与交互方向

整体风格：

- 工业制造感、可信、清晰、高效率。
- 不要做成大段文字的海外品牌叙事。
- 不要过多抽象渐变、装饰图形或过重动画。
- 产品和工厂实拍是第一视觉资产。

色彩建议：

- 主色可沿用 TEAO 橙色，增强品牌连续性。
- 搭配深灰、白色、浅灰，突出工业感。
- 中文站可以适当增加红橙强调，但不要做成廉价促销风。

布局建议：

- 首页模块更密集，减少超大留白。
- 卡片内文字控制在 1 到 3 行。
- 图文并排时优先让图片占更大权重。
- 移动端第一屏必须看到产品、实力标签和联系方式。

交互建议：

- 首页产品卡片可快速进入分类。
- 产品页支持快速询价浮窗。
- 移动端固定电话/微信/询盘按钮。
- 表单支持上传图纸、上传图片、填写年用量和应用场景。
- 产品视频不要提供明显下载入口，保持普通用户下载摩擦。

- 汽车内饰阻尼器

- 轴向阻尼器
- 圆筒阻尼器
- 桶形阻尼器
- 缓冲器
- 缓降阻尼器
- 锁扣
- Push-Push 锁扣

页面策略：

- 首页抢“阻尼器厂家 / 汽车内饰阻尼器厂家 / 齿轮阻尼器厂家”。
- 分类页抢产品大词，例如“齿轮阻尼器 / 旋转阻尼器”。
- 产品页抢型号词和长尾应用词。
- 应用页抢“汽车杯托阻尼器 / 手套箱缓降阻尼器 / 汽车内饰缓冲机构”等。
- 技术文章抢选型类长尾词。

搜索引擎策略：

- 确保服务端渲染，避免百度只看到空壳。
- 生成 `sitemap.xml`，提交百度站长、360、搜狗等。
- 保留 `robots.txt`。
- 首页、分类页、产品页都写独立 title/description。
- 图片加中文 alt。
- 重要内容不要只放图片里。
- 新闻和技术文章要稳定更新，但不要堆无意义软文。

AI/GEO 策略：

- 中文站也可以保留 `/llms.txt` 和 `/llms-full.txt`，输出中文公司简介、产品分类、核心能力和联系信息。
- 产品别名要统一：齿轮阻尼器/旋转阻尼器，轴向阻尼器/圆筒阻尼器/桶形阻尼器，不要拆成互相竞争的独立概念。

## 9. URL 与迁移策略

这是替换中文站最容易出问题的部分。

当前中文站 sitemap 约 51 条 URL，且包含多种历史结构：

- `/gear-damper/...html`
- `/axial-dampers/...html`
- `/applications/...`
- `/news/...html`
- `/index.php/...`
- `/zh-hans/torque/...`

建议执行方式：

1. 导出旧站 sitemap 和服务器访问日志。
2. 按页面类型分组：产品、分类、应用、新闻、工具、关于、联系。
3. 给每个旧 URL 指定新 URL。
4. 高价值产品 URL 尽量一对一保留或 301 到对应产品详情页。
5. 不要把所有旧 URL 都跳首页。
6. 不要使用 302 临时跳转做正式迁移。
7. 切站后 2 到 4 周持续检查 404、收录、流量和询盘。

新站 URL 可选方案：

方案 A：复用英文站风格的短路径，便于长期维护。

- `/products`
- `/gear-damper`
- `/gear-damper/{slug}`
- `/axial-damper`
- `/axial-damper/{slug}`
- `/applications/automotive`
- `/quality`
- `/about`
- `/contact`

方案 B：保留中文旧站的 `.html` 产品路径，最大化减少 SEO 波动。

- `/gear-damper/gear-rotary-damper-rd-t038-v038.html`
- `/axial-dampers/axial-barrel-damper-rd-t138.html`

建议：如果旧站已有收录和询盘，先用方案 B 或至少保留一对一 301；如果旧站权重不高，可以采用方案 A，但必须做完整重定向表。

## 10. 技术方向

如果新建项目，建议仍采用当前英文站相近技术栈，降低迁移成本：

- Next.js App Router
- TypeScript
- Tailwind CSS
- 数据库：SQLite/Turso 或其他轻量数据库
- 产品、新闻、媒体、询盘后台
- 服务端渲染
- 动态 sitemap
- 表单邮件通知
- 基础访问统计与询盘追踪

中文站额外注意：

- 如果部署在中国大陆服务器，需要确认 ICP 备案、公安备案、服务器/CDN 线路。
- 接入百度统计或其他国内统计工具。
- 接入百度站长平台。
- 表单要防垃圾提交。
- 图片和视频压缩要兼顾国内访问速度。
- 微信二维码、电话、邮箱、地图要明显。

可复用英文站模块：

- 产品数据结构
- 产品图库
- 视频播放逻辑

## 13. 不建议做的事

- 不要直接把英文文案逐句翻译成中文。
- 不要把首页做成长篇品牌介绍。
- 不要只放产品分类，不展示工厂、检测、认证和客户。
- 不要忽略旧中文站 URL。
- 不要把所有历史页面都跳转到首页。
- 不要用大量库存图替代工厂实拍和产品实拍。
- 不要在移动端隐藏电话、微信和询盘入口。
- 不要把产品参数放在图片里，搜索引擎和客户都不方便读取。

## 14. 最终建议

中文新站应该走“制造实力型 B2B 官网”路线：

- 第一屏强定位。
- 首页强产品、强应用、强工厂、强质量、强询盘。
- 产品页强参数、强图纸、强视频、强推荐型号。
- 应用页强场景、强解决方案。
- SEO 保留旧站权重，同时补齐中文长尾关键词。

如果只“复刻英文站”，会比旧中文站好看，但不一定更适合国内客户。如果按上面方向重构，才能既继承英文站的专业体系，又符合中国客户快速判断供应商实力和快速询价的浏览习惯。
