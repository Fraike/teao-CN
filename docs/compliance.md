# 合规说明

> 最后更新：2026-11-26。以下为当前实现说明，不构成正式法律意见；上线前建议由公司法务/顾问复核。

## 页面

- 隐私政策：`https://www.chinateao.com/privacy/`
- 服务条款：`https://www.chinateao.com/terms/`
- 页脚：隐私政策、服务条款、ICP 备案号与工信部链接
- 联系表单：勾选同意隐私政策后才能提交

> 服务条款页与隐私政策更新已于 2026-11-26 部署上线。

## 收集的信息

联系表单收集：

- 姓名、公司、电话、邮箱、感兴趣的产品、年用量、需求描述
- 提交时间、IP、浏览器/设备基础信息（用于防滥用与安全审计）

后台询盘管理会保存上述信息；企业微信 webhook 会把询盘内容发送到公司内部群，仅限相关负责人查看。

## 使用目的

- 回复询盘、选型、报价、样品和技术资料
- 订单/售后/业务沟通
- 防垃圾提交和网站安全
- 法律法规要求的其他用途

不出售个人信息，不用于无关营销。

## 第三方服务

目前使用：

- 阿里云：服务器与数据库
- 企业微信：询盘即时通知
- 网易企业邮：业务邮件（域名 MX）

上述服务商位于中国境内。如未来涉及跨境传输，将依法另行告知并取得同意。

## 保存期限

- 一般自最后一次业务沟通起不超过 3 年
- 合同、发票、税务等法律法规另有保存要求的，从其规定
- 超期删除或匿名化

## 用户权利

可通过 `info@chinateao.com` 或 `18928247197` 查询、更正、补充、删除、撤回同意或停止使用；也可向网信、市场监管等部门投诉。

## 后台与数据安全

- 后台仅管理员可访问，登录使用 HTTPS + HttpOnly Cookie
- 询盘在 SQLite `inquiries` 表；支持状态标记、CSV 导出、删除
- 企业微信 webhook 地址只存在服务器 `.env.local`，不进仓库
- 建议：限制企业微信群成员、定期轮换管理员密码、定期备份数据库

## 运营注意事项

- 如属地公安要求，需完成公安联网备案，并在页脚补充公安备案号与链接
- 新增访问分析/广告追踪时，先更新隐私政策并处理 Cookie 同意
- 新增第三方服务（短信、CRM、云存储）时，补充服务商与跨境说明
- 定期检查页脚 ICP 备案号与工信部链接
- 保留老站/老备案期间的过渡说明，避免用户混淆
