# TEAO 中文独立站资料准备与调整清单

整理日期：2026-06-10  
用途：在正式新建中文站项目前，先把国内站需要确认的资料、内容口径、合规项和迁移项收齐。

## 1. 这份清单的目的

上一版方向文档已经确定了大方向：中文站不做英文站逐字翻译，而做“更适合国内 B2B 制造业客户浏览习惯”的本土化官网。

现在正式开工前，需要你补齐几类资料。补完后，我们再做第二版方案：

- 明确中文站到底主打哪些客户、产品和应用。
- 确认哪些实力数据可以公开展示。
- 确认哪些客户、证书、工厂照片、视频可以公开使用。
- 确认国内合规、备案、统计、搜索平台和询盘方式。
- 整理旧中文站 URL，避免切站后 SEO 权重丢失。

## 2. 优先级最高：先给这些资料

如果只先准备一批资料，建议按这个顺序给。

### 2.1 中文站核心定位

需要你确认：

- 中文站主打“汽车内饰阻尼器厂家”，还是“阻尼器/锁扣综合厂家”？
- 重点客户是汽车主机厂、Tier-1、家电卫浴、办公设备，还是都要兼顾？
- 国内客户更看重“现货标准品”还是“按图定制”？
- 是否要突出“源头厂家”“工厂直供”“支持打样”“非标定制”这些国内常用表达？

建议你给我的格式：

```text
主定位：
第一重点客户：
第二重点客户：
最想推广的产品：
最想弱化的产品：
中文站最重要的转化动作：
```

### 2.2 产品线与产品优先级

需要你提供或确认：

- 中文产品分类最终名称。
- 每个分类下最重要的型号。
- 哪些型号是主推款。
- 哪些型号已经停产、少推或不希望公开。
- 哪些产品支持定制，哪些只做标准款。

建议产品分类先按下面口径确认：

| 英文站分类 | 中文主名称 | 中文别名 | 是否保留为一级分类 |
| --- | --- | --- | --- |
| Gear Dampers | 齿轮阻尼器 | 旋转阻尼器、齿轮缓冲器 | 待确认 |
| Axial Dampers | 轴向阻尼器 | 圆筒阻尼器、桶形阻尼器、轴阻尼器 | 待确认 |
| Glove Box Dampers | 手套箱阻尼器 | 手套箱缓降阻尼器、汽车杂物箱阻尼器 | 待确认 |
| Latches | 锁扣 | Push-Push 锁扣、汽车内饰锁扣 | 待确认 |
| Other Products | 其他零部件 | 定制机构、收纳盒机构、缓冲组件 | 待确认 |
| Air Dampers | 空气阻尼器 | 空气缓冲器 | 待确认 |
| Linear Dampers | 线性阻尼器 | 直线阻尼器 | 待确认 |

特别需要你确认：旧中文站里有“空气阻尼器”“线性阻尼器”等入口，新英文站主结构里不一定是重点。新中文站要不要继续保留这些作为一级分类，会影响 SEO 和导航。

### 2.3 真实实力数据

国内站首页要直接展示实力数字，但必须真实、可公开。

需要你确认：

- 公司成立年份。
- 是否继续写 20+ 年。
- 年产能是否继续写 8000 万件。
- 工厂面积能否公开。
- 员工人数能否公开。
- 注塑机数量、自动化线数量、检测设备数量能否公开。
- 是否可以写 100% 扭矩检测。
- 是否可以写 IATF 16949、ISO 14001。
- 是否有实验室、寿命测试、高低温测试、盐雾测试等。

建议你给我的格式：

```text
成立年份：
年产能：
工厂面积：
员工人数：
注塑机数量：
自动化线数量：
核心检测设备：
可公开认证：
可公开专利数量：
不可公开的数据：
```

### 2.4 工厂、设备、检测、证书素材

国内客户判断“是不是真厂家”，主要看真实照片和视频。

需要你准备：

- 工厂外观照片。
- 办公区/展厅照片。
- 注塑车间照片。
- 自动化装配线照片。
- 模具或工装照片。
- 检测设备照片。
- 寿命测试、高低温测试、扭矩测试视频。
- 生产线短视频。
- 产品应用短视频。
- IATF 16949、ISO 14001 证书图片。
- 专利证书图片。

建议每个素材给一句说明：

```text
文件名：
展示内容：
能否公开：
适合放在哪一页：
是否需要打码：
```

### 2.5 客户 Logo 与案例授权

客户背书对国内站很关键，但不能乱放。

需要你确认：

- BYD、吉利、奇瑞、上汽、一汽、广汽、长安、长城、东风、蔚来、小鹏、理想等 Logo 是否有公开展示授权。
- 哪些只能内部展示，不能上官网。
- 能否写“服务汽车及家电供应链客户”这种模糊表述。
- 是否有可公开案例：某类车型、某类内饰部件、某类家电产品，但不写具体客户名。

建议把客户分三类：

| 类型 | 处理方式 |
| --- | --- |
| 可公开 Logo | 首页和客户案例页展示 |
| 可模糊展示 | 写行业/应用，不放 Logo |
| 不可公开 | 不进入官网 |

### 2.6 联系方式与询盘流程

国内站转化入口要比英文站更直接。

需要你提供：

- 国内客服电话。
- 国内销售手机号。
- 微信二维码。
- 企业微信二维码，如果有。
- QQ 是否还需要展示。
- 邮箱。
- 地址。
- 工作时间。
- 询盘后由谁接收。
- 表单是否需要邮件通知、企业微信通知、短信通知。
- 客户提交图纸后，期望多久回复：例如 2 小时、24 小时。

建议询盘表单字段先确认：

- 姓名
- 公司名称
- 手机号
- 微信号
- 产品类型
- 应用场景
- 年用量
- 目标扭矩
- 是否有图纸/样品
- 文件上传
- 备注

特别需要你确认：是否允许客户上传图纸、图片、PDF、CAD 文件。如果允许，要确定文件大小、存储位置和内部查看流程。

## 3. 国内站特有事项

### 3.1 备案与服务器位置

如果中文站部署在中国大陆服务器，通常需要先处理：

- ICP 备案。
- 公安联网备案。
- 页面底部展示备案号和公安备案号。

如果部署在香港、海外或国际 CDN：

- 可能不需要 ICP 备案，但国内访问速度、百度抓取稳定性、微信打开速度要单独评估。
- 如果目标客户主要在中国大陆，仍建议优先考虑国内可稳定访问的服务器/CDN方案。

需要你确认：

```text
www.chinateao.com 当前备案主体：
当前 ICP 备案号：
是否已有公安备案：
新站计划部署位置：
是否继续用当前域名：
是否保留 www：
```

参考入口：

- 工信部 ICP/IP 地址/域名信息备案管理系统：https://beian.miit.gov.cn/
- 公安机关互联网站安全管理服务平台：https://www.beian.gov.cn/

### 3.2 隐私与表单合规

中文站如果收集姓名、手机、微信、公司、图纸、IP、访问行为等信息，应准备隐私政策和必要的用户告知。

需要你确认：

- 是否收集手机号。
- 是否收集微信号。
- 是否允许上传图纸。
- 是否接入百度统计、其他统计或广告追踪。
- 是否需要 Cookie/隐私提示。
- 表单数据保存多久。
- 谁能在后台查看询盘。

建议做法：

- 联系表单旁边增加“提交即表示同意隐私政策”。
- 隐私政策说明收集目的：报价、选型、售后联系。
- 只收集询盘必要字段，不做过度采集。
- 后台询盘加权限控制。

参考依据：

- 《中华人民共和国个人信息保护法》要求个人信息处理遵循合法、正当、必要、诚信、公开透明等原则。

### 3.3 百度、360、搜狗与统计

国内自然搜索至少要考虑百度，360、搜狗可以后续补。

需要你确认：

- 是否有百度搜索资源平台账号。
- 是否有百度统计账号。
- 是否投放百度推广。
- 是否需要接入 360 站长平台、搜狗站长平台。
- 是否需要保留 Google Analytics。
- 是否要接入抖音、巨量、腾讯广告等转化追踪。

建议上线前准备：

- 百度搜索资源平台站点验证。
- `sitemap.xml` 提交。
- `robots.txt` 检查。
- 死链/改版规则提交。
- 百度统计或其他国内统计代码。
- 表单提交事件、电话点击、微信二维码点击事件。

参考入口：

- 百度搜索资源平台站点管理：https://ziyuan.baidu.com/site/index
- 百度搜索资源平台普通收录：https://ziyuan.baidu.com/sitemap/index
- 百度统计：https://tongji.baidu.com/

## 4. 内容口径需要调整的地方

### 4.1 英文站内容要改成国内表达

英文站里常见的表达：

- global OEM
- Tier-1
- international B2B programs
- engineered for stable damping
- soft closing
- repeatable mass production

中文站建议改成：

- 汽车主机厂及一级供应商配套
- 支持汽车内饰、家电、卫浴、办公设备等行业
- 支持按图纸、样品和应用场景定制
- 稳定扭矩、静音缓冲、开合手感可调
- 从打样到量产交付
- 扭矩检测和批次追溯

### 4.2 首页不要像英文站那样留太多“品牌感空白”

国内站首页建议更紧凑：

- 第一屏：定位 + 产品图 + 实力数字 + 电话/微信/询盘。
- 第二屏：产品分类。
- 第三屏：应用场景。
- 第四屏：工厂实力。
- 第五屏：质量认证。
- 第六屏：客户/案例。
- 第七屏：项目流程。
- 第八屏：强询盘。

### 4.3 产品页不要长篇叙事

产品页优先顺序：

1. 产品图和型号。
2. 参数表。
3. 尺寸图。
4. 性能曲线。
5. 应用视频。
6. 推荐应用。
7. 相关产品。
8. FAQ 和 SEO 内容。

国内客户通常先看“能不能用”，再看详细说明。

### 4.4 制造实力要比品牌故事更重要

关于我们页不要只写发展历程。建议改成：

- 公司概况。
- 工厂实拍。
- 生产能力。
- 工程能力。
- 质量体系。
- 客户行业。
- 联系方式。

品牌故事可以保留，但不要放在最前面。

## 6. URL 迁移需要你确认

当前中文站 sitemap 里大约有 51 条 URL，包含产品页、分类页、应用页、新闻页、工具页和 `index.php` 历史路径。

需要做一张迁移表：

| 旧 URL | 旧页面类型 | 新 URL | 处理方式 | 备注 |
| --- | --- | --- | --- | --- |
| `/gear-damper/...html` | 产品详情 | 待定 | 301 或保留 | 重点 |
| `/axial-dampers/...html` | 产品详情 | 待定 | 301 或保留 | 重点 |
| `/applications/...` | 应用页 | 待定 | 301 | 重点 |
| `/news/...html` | 新闻页 | 待定 | 301 或保留 | 中等 |
| `/index.php/...` | 历史路径 | 待定 | 301 | 需要清理 |
| `/zh-hans/torque/...` | 工具页 | 待定 | 保留或 301 | 看流量 |

需要你确认：

- 旧中文站是否有百度收录和询盘。
- 哪些旧产品 URL 必须保留。
- 新中文站是否接受英文 slug。
- 是否希望产品 URL 用中文拼音、英文型号，还是保留旧 `.html`。

我的建议：

- 产品详情页优先保留旧 URL 或一对一 301。
- 分类页可以逐步调整为更清晰的新路径。
- 不要把所有旧 URL 都跳首页。
- 切站后要持续看 404 日志。

## 8. 页面内容需要你最终确认的点

### 首页

需要确认：

- 副标题。
- 4 到 6 个实力数字。
- 首页主推产品顺序。

- 是否展示证书。

### 产品中心

需要确认：

- 分类名称。
- 分类排序。
- 每个分类的中文说明。
- 每个分类的主图。
- 每个分类的推荐型号。

### 应用领域

需要确认：

- 家电、卫浴、办公设备、工业设备的排序。

### 制造实力

需要确认：

- 是否重点展示工厂视频。
- 是否展示设备清单。

### 联系页

需要确认：

- 电话、微信、邮箱、地址。
- 地图是否展示。
- 是否支持上传图纸。
- 表单字段。
- 表单提交后的提示语。

## 11. 资料确认后我会输出什么

资料补齐后，我建议下一步输出三份东西：

## 12. 当前不建议马上开始编码

原因很直接：
