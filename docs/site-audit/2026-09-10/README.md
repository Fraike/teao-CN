# Header 产品分类 404 修复

日期：2026-09-10。此文件更新 2026-09-09 的首批样板状态。

## 原因

普通 Header 和 Footer 仍指向未实现的 `/products/gear-damper` 等开发地址；首批样板只实现了 `/gear-damper/`，且使用另一套 Header。用户实际打开的 localhost:3000 是旧的 `npm run start` 构建，不支持热更新。

## 已实施

- 普通 Header、Footer、首页产品卡片连接同一份分类原址配置。
- 分类页和首页使用同一个 Header/Footer，保留当前页面视觉风格。
- 下列五个分类及原有分页本地渲染，标题、主图、文案和型号列表各自独立。
- 旧开发分类路径兼容跳转到对应线上原路径；线上原路径不更名。
- 产品中心使用真实分类目录替换五条开发种子数据；未改写数据库。
- 未迁入的详情入口明确标注「查看原站详情」，保留原站完整 URL；只有 RD-T038/RD-V038 详情为本地样板。

## 数据来源与复现

- `snapshots/` 保存本次成功 HTTP 200 的分类及分页原始 HTML；齿轮第一页使用 2026-09-09 已保存快照。
- `assets.json` 保存本地素材与线上资源 URL、SHA-256 的对应关系。
- `scripts/import-category-snapshots.py` 从快照生成分类内容和路由配置。脚本不写数据库；已下载资源会复用。
- 2026-09-09 的全站 403 清单仍属于历史采集结果，本次仅补齐这些分类与分页，不能据此宣称全站抓取完成。

## 范围边界

完整产品详情、应用、新闻、支持等全站内容尚未全部本地化。分类/目录仍设置 noindex，等待内容及整站上线验收；此次仅更新本地预览，没有线上部署。产品参数冲突继续按 2026-09-09 清单核对。
