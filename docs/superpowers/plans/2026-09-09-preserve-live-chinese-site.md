# 中文站保留线上结构的首批优化执行计划

**目标：** 以 https://www.chinateao.com/ 为唯一 URL 和栏目结构依据，完成可追溯盘点及一个分类、一个产品详情本地样板。

**授权依据：** 用户明确要求保留线上页面结构与 URL，并已同意开始执行盘点、对照、样板。

**边界：** 保留当前未提交修改；不写生产数据、不部署、不推送。样板不代表整站迁移完成。

**实现：** 抓取 sitemap、首页导航及递归站内链接，保存实际请求 URL、状态、跳转、标题、描述、来源和本地对应状态。URL 不转小写、不删除空格、不重命名、不统一替换历史路径。样板用已核实的线上数据，目录尾斜杠和 .html 原样保留。

- [ ] 获取线上快照，交叉核对 sitemap、导航、分页及站内链接；记录抓取边界。
- [ ] 生成 JSON 清单与 Markdown 逐页对应表；区分有效页面、跳转、失效和未验证。
- [ ] 选取实际可访问分类及其产品，记录模块顺序、原始文案与素材来源。
- [ ] 为原路径解析和不存在路径编写回归测试，验证失败后实现白名单路由。
- [ ] 沿用现有中文视觉变量，优化分类与产品详情，保留原栏目与产品资料。
- [ ] 运行回归测试、类型检查、lint、构建和本地 HTTP/浏览器检查；记录遗留问题与预览地址。
