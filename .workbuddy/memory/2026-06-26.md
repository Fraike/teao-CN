## TEAO 中文站首页 UI 设计（V1 原型）

基于以下文档和项目资料完成了中文站首页设计原型：
- `docs/chinese-site-rebuild-direction.md` — 重构方向文档（核心参考）
- `docs/chinese-site-preparation-checklist.md` — 资料准备清单
- 英文站 teao-website 项目的产品数据、品牌色、客户信息等
- 已有 `homepage-ui-preview.html` 的结构基础

### 设计产出
**文件**: `teao-cn-homepage-v1.html` — 面向国内 B2B 采购人员的首页完整 UI 原型

### 设计要点
1. **Hero 区**：强定位「源头厂家」，突出 IATF/ISO/产能/检测等信任标签，右侧放快速询盘卡片 + 热线条
2. **数据栏**：5 个核心实力数字悬浮在 Hero 下方，采购一眼看到关键指标
3. **产品中心**：5 大产品线卡片，每张含参数标签 + 获取报价入口
4. **应用领域**：场景驱动布局（汽车杯托、手套箱、眼镜盒等），每个场景配推荐型号
5. **制造实力**：深色背景 + 车间实拍 + 6 项能力网格
6. **质量认证**：证书卡 + 4 步 QC 流程并排展示
7. **客户案例**：汽车品牌 Logo 墙（待授权替换）
8. **询盘 CTA**：深色背景 + 表单（支持图纸上传）
9. **移动端**：底部固定三按钮（电话 / 微信 / 发图纸）
10. **顶部栏**：电话 / 微信 / 邮箱一目了然

### 与旧版 homepage-ui-preview.html 的主要区别
- 更紧凑的信息密度，减少留白
- 产品卡片增加了参数标签和报价入口
- 应用场景从纯文字改为图标+推荐型号卡片
- 增加了移动端固定底部转化栏
- Hero 右侧询盘面板增加了热线条
- 整体视觉更偏工业制造感，减少"品牌感空白"

## TEAO 中文站「关于我们」页面 UI 设计（V1 原型）

基于英文站 About 页面结构（`teao-website/src/content/about.ts` + `src/components/about/`）和中文站首页视觉系统完成了中文站「关于特澳」页面设计原型。

### 设计产出
**文件**: `teao-cn-about-v1.html` — 面向国内采购的「关于特澳」页面完整 UI 原型

### 页面模块
1. **Page Hero**：公司全称 + 20+ 年定位 + 4 个信任徽章 + 右侧关键数据卡片（成立年份/基地/产品线/行业）
2. **公司简介**：左文右图布局，3 段公司介绍文字 + 4 个关键信息卡（基地/成立时间/核心产品/服务客户）
3. **发展历程**：5 节点时间线（2001 成立 → 2009 进汽车 → 2014 搬迁 → 2021 创新 → 2025 扩建）
4. **经营数据**：6 张数据卡（100+ 方案 / 4 行业 / 100% 检测 / 6% 研发投入 / 20+11 产线 / 200+ 客户）
5. **核心能力**：3 张大图卡片（工程支持 / 注塑生产[高亮] / 自动化装配）
6. **认证与专利**：左侧白底体系认证（IATF/ISO）+ 右侧深色专利证书（3 项专利占位）
7. **服务行业**：5 张行业卡片（汽车 / 家电 / 卫浴 / 医疗 / 工业）
8. **企业责任**：4 张价值卡（教育支持 / 公益参与 / 环境保护 / 社区贡献）
9. **团队与文化**：左侧文化介绍+3 项亮点 + 右侧 4 张团队照片占位
10. **询盘 CTA**：与首页一致，深色背景 + 表单（支持图纸上传）
11. **移动端**：底部固定三按钮

### 内容来源
- 公司历史、里程碑数据来自英文站 `src/content/about.ts` 的 `timeline` 和 `businessStats`
- 专利信息来自英文站 `patentCertificates`
- 行业覆盖来自英文站 `industries`
- 企业责任来自英文站 `corporateValues`
- 团队文化来自英文站 `peopleCulture`
- 地址更新为「广东省东莞市黄江镇北岸三街2号」（来自 timeline 2025 条目）
